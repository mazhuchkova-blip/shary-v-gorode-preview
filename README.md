# ШарыВГороде — первый шаблон

Откройте `index.html` в браузере. Публикация и отправка форм не настроены.

Файлы:

- `index.html` — адаптивная страница;
- `preview-desktop.png` — превью первого экрана;
- `brief.md` — единый бриф, спорные условия и список недостающего;
- `research.md` — разбор трёх сайтов-референсов;
- `assets/logo-clean.png` — очищенный логотип без голубого фона;
- `assets/hero-balloons.mp4` — зацикленное видео с живым движением шаров;
- `assets/hero-balloons-poster.jpg` — запасной кадр на время загрузки видео.

Следующий шаг после согласования дизайна: заменить плейсхолдер фото, добавить работы Юлии и подключить реальный контакт для заказа.

На первом экране используется настоящее видео, как в референсе, поэтому шары двигаются естественно. Ниже по странице блоки мягко появляются при прокрутке. Для пользователей, отключивших анимацию в системе, вместо видео показывается статичный кадр.
