# ШарыВГороде — первый шаблон

Откройте `index.html` в браузере. Публикация и отправка форм не настроены.

Файлы:

- `index.html` — адаптивная страница;
- `brief.md` — единый бриф, спорные условия и список недостающего;
- `research.md` — разбор трёх сайтов-референсов;
- `assets/logo-clean.png` — очищенный логотип без голубого фона;
- `assets/hero-sky-v2.jpg` — реалистичный фон неба;
- `assets/hero-bubble.png`, `hero-heart-peach.png`, `hero-heart-white.png`, `hero-round-pearl.png` — отдельные слои шаров первого экрана.

Следующий шаг после согласования дизайна: заменить плейсхолдер фото, добавить работы Юлии и подключить реальный контакт для заказа.

На первом экране используется собственная композиция: реалистичные шары независимо покачиваются на фоне неба. Ниже по странице блоки мягко появляются при прокрутке. Для пользователей, отключивших анимацию в системе, первый экран остаётся статичным.
