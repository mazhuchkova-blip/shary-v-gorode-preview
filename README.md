# ШарыВГороде — первый шаблон

Откройте `index.html` в браузере. Публикация и отправка форм не настроены.

Файлы:

- `index.html` — адаптивная страница;
- `preview-desktop.png` — превью первого экрана;
- `brief.md` — единый бриф, спорные условия и список недостающего;
- `research.md` — разбор трёх сайтов-референсов;
- `assets/logo-original.jpg` — логотип из переписки;
- `assets/hero-reference-style.png` — новый визуал первого экрана в стилистике референса.

Следующий шаг после согласования дизайна: заменить плейсхолдер фото, добавить работы Юлии и подключить реальный контакт для заказа.

В шаблоне уже есть спокойное движение фотослоя с шарами на первом экране и мягкое появление блоков при прокрутке. Для пользователей, отключивших анимацию в системе, эффекты автоматически выключаются.
